### 📥 Download Options (4 Qualities)

1. **720p HD** - Basic quality
   - Resolution: 1280 × 720
   - File Size: 128 MB
   - Perfect for mobile devices

2. **1080p Full HD** - Standard quality
   - Resolution: 1920 × 1080
   - File Size: 245 MB
   - Great for web viewing

3. **1440p 2K** - Recommended quality ⭐
   - Resolution: 2560 × 1440
   - File Size: 512 MB
   - Best balance of quality and size

4. **2160p 4K** - Premium quality
   - Resolution: 3840 × 2160
   - File Size: 1.2 GB
   - Maximum visual quality

## 🔄 How to Use

2. Click "Watch Preview" to see the video
3. Choose your preferred quality from the download options
4. Watch the download progress simulation
5. Fill out the contact form for inquiries

## 💡 Customization

### Change Video Source
Replace the video URL in the `<video>` tag:
```html
<source src="your-video-url.mp4" type="video/mp4">
```

### Modify Colors
Update CSS variables in `styles.css`:
```css
--primary-color: #6366f1;
--secondary-color: #ec4899;
```

### Update Company Information
Edit the footer and contact sections in `index.html`
